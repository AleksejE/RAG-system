# src

Исходный код приложения. Каждая подпапка отвечает за один этап работы RAG-системы.

| Папка / файл | Назначение |
|---|---|
| `config/` | Настройки проекта: читает переменные из `.env` и отдаёт их остальным модулям. |
| `parsing/` | Скачивает HTML-страницу Конституции и разбивает её на блоки «заголовок + текст». |
| `chunking/` | Режет блоки на чанки и добавляет к ним метаданные (`Header`, `page_number`). |
| `embeddings/` | Загружает модель эмбеддингов `BAAI/bge-m3`. Используется и при индексации, и при поиске. |
| `vector_store/` | **Модуль БД.** Создаёт коллекцию в Qdrant, записывает в неё чанки и подключается к ней. |
| `main.py` | Точка входа. Команды `index` (построить базу) и `search` (проверить поиск без LLM). |

## Как данные проходят через модули

Индексация (`index`):

```
garant.ru → parsing → chunking → embeddings → vector_store (Qdrant)
```

Проверка поиска (`search`):

```
запрос → embeddings → vector_store (Qdrant, top-k) → найденные фрагменты
```

Модуль `rag/` (поиск + генерация ответа через Groq) добавляется отдельно и
использует `vector_store.load_vector_store()` из этой части.
