# chunking

Разбиение текста на фрагменты (чанки) и добавление метаданных.

| Файл | Назначение |
|---|---|
| `splitter.py` | Режет текст каждого блока на чанки с помощью `RecursiveCharacterTextSplitter` Заголовок блока добавляется в начало текста чанка, чтобы он попадал в эмбеддинг. Метаданные: заголовок блока (`Header`), номер статьи (`article`, строка `"80"`, `"67.1"` или `None` для преамбулы) и примерный номер страницы (`page_number`). |

## Параметры (из `.env`)

- `CHUNK_SIZE` (по умолчанию 600) задаёт максимальный размер чанка в символах.
- `CHUNK_OVERLAP` (по умолчанию 100) задаёт, сколько символов соседние чанки делят между собой, чтобы не терялся контекст на границах.
- `PAGE_SIZE_CHARS` (по умолчанию 1500) задаёт, сколько символов считается одной страницей.

## Важно про `page_number`

Номер страницы не берётся из реального документа, а оценивается по количеству символов от начала текста. Это приблизительная ссылка, а не точная страница печатного издания.

## Функции

- `extract_article_number(header)` достаёт номер статьи из заголовка.
- `create_chunked_documents(raw_blocks)` возвращает список `Document`, который передаётся в `vector_store`.
