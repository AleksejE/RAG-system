# embeddings

Модель эмбеддингов, которая переводит текст в векторы.

| Файл | Назначение |
|---|---|
| `embedder.py` | Загружает модель `BAAI/bge-m3` через `HuggingFaceEmbeddings`. Модель кэшируется (`lru_cache`), поэтому загружается только один раз за запуск. |

## Почему это отдельный модуль

Одна и та же модель нужна в двух местах: при индексации (`vector_store`) и при поиске (`rag`). Если бы модели при индексации и при поиске различались, векторы вопросов и документов оказались бы несравнимыми, и поиск бы не работал. Отдельный модуль гарантирует, что модель везде одна.

## Параметры (из `.env`)

- `EMBEDDING_MODEL` задаёт модель (по умолчанию `BAAI/bge-m3`).
- `EMBEDDING_DEVICE` задаёт устройство: `cpu` или `cuda`, если есть видеокарта.

При смене модели нужно поменять `EMBEDDING_DIM` под её размерность и заново выполнить `index`.
