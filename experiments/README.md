# experiments

Эксперименты, которые не входят в само приложение, но помогают подобрать его параметры:
например, сравнение разных `CHUNK_SIZE`, моделей эмбеддингов, значений `TOP_K_RESULTS` или промптов.

Каждый эксперимент оформляем отдельным ноутбуком или скриптом с понятным названием
(`chunk_size_comparison.ipynb`) и кратко записываем сюда его вывод.
