# analytics

Оценка качества работы RAG-системы.

| Файл | Назначение |
|---|---|
| `eval_questions.json` | Контрольные вопросы на русском и английском с номерами статей, в которых есть ответ. |
| `evaluate_retrieval.py` | Проверяет поиск: попадает ли нужная статья в top-k. Считает Hit@k и MRR. LLM не вызывается, ключ Groq не нужен. |

## Запуск

```bash
uv run python -m analytics.evaluate_retrieval          # k = TOP_K_RESULTS
uv run python -m analytics.evaluate_retrieval --k 3
```

## Метрики

- **Hit@k** показывает долю вопросов, для которых чанк нужной статьи нашёлся среди первых k.
- **MRR** (mean reciprocal rank) равен среднему значению 1/место первого правильного чанка. Если чанк не найден, вопрос даёт 0.
